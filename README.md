# On the Robustness of Rashomon Partial Dependence Profiles: Theory of Optimal Thresholds and Empirical Comparison of Sampling Methods

This repository was created to reproduce the experimental work included in the paper entitled "On the Robustness of Rashomon Partial Dependence Profiles: Theory of Optimal Thresholds and Empirical Comparison of Sampling Methods", submitted to the AutoML 2026 conference Method Track.

---

## 📋 Experimental Checklist & Reproducibility

In compliance with AutoML benchmarking standards, this repository provides:
* **Uniform Evaluation:** All compared methods use identical benchmarks, data subsets, and evaluation protocols.
* **Statistical Rigor:** Experiments are repeated across multiple random seeds to account for stochasticity; uncertainty (standard errors) and statistical significance are reported.
* **Ablation Support:** Built-in support for testing the impact of noise levels ($v^2 \in \{1, 4, 9\}$), Rashomon thresholds ($\epsilon$), and different sampling strategies.
* **Direct Result Access:** Users can skip computation and directly audit pre-generated datasets in `/data` and evaluation results in `/results`.

---

## 📂 Repository Structure

The repository is organized to allow both full reproduction and direct result inspection:

### 📊 Data (`/data`)
Synthetic datasets follow the naming convention `synth_{setup}_{noise}.csv`:
* **Setups (1, 2, 3):** Refer to the three main data-generating scenarios (including updated $X_1$ transformations for Scenario 3).
* **Noise Levels (1, 4, 9):** Represent the variance levels ($v^2$) used to test profile robustness.
* **Test Sets:** Corresponding `test_synth_...` files are provided for out-of-sample evaluation.

### 📈 Results (`/results`)
Contains the raw experimental logs, metric tables, and statistical outputs generated by the evaluation pipeline.

### 🛠️ Codebase
* `main.py`: The entry point for executing the full experimental pipeline.
* `scenarios.py` & `utils.py`: Definitions of the 72 experimental configurations and core helper functions.
* `01_data_generation.ipynb` to `03_evaluation.ipynb`: Step-by-step interactive workflow.
* `04_interactive_exploration.ipynb`: **Minimal example** for rapid replication on toy data.
* `pyproject.toml` & `uv.lock`: Environment and dependency definitions.

## 🚀 Getting Started

### Prerequisites
- Python 3.8+
- Core Stack: `numpy`, `pandas`, `scikit-learn`, `matplotlib`, `seaborn`, `jupyter`

### Installation
```bash
git clone [https://github.com/mustafacavus/Rashomon-PDP-Robustness.git](https://github.com/mustafacavus/Rashomon-PDP-Robustness.git)
cd Rashomon-PDP-Robustness
# If using uv:
uv sync
```

### Running the Experiments

The full study can be repoduced by running:

```bash
python main.py
```

Or explore the steps interactively by opening the Jupyter notebooks in numerical order (`01` to `03`).
